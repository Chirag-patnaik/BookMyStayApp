**Book My Stay App**

Hotel Booking Management System


Book My Stay App is a console-based Hotel Booking Management System developed using Core Java and Data Structures.
The project demonstrates how various data structures and object-oriented programming concepts can be applied to solve real-world hotel booking problems.

---

Technologies Used

- Core Java
- Object-Oriented Programming (OOP)
- Collections Framework
- HashMap
- HashSet
- ArrayList
- Queue
- Stack
- Multithreading
- File Handling
- Serialization
- Git & GitHub

---

Features

- Application Entry & Welcome Screen
- Room Management
- Centralized Inventory
- Room Search
- Booking Queue (FIFO)
- Reservation Confirmation
- Add-On Services
- Booking History
- Error Handling & Validation
- Booking Cancellation & Inventory Rollback
- Concurrent Booking Simulation
- Data Persistence & System Recovery
